# qa_python
Описание тестов:
1. setup_method Этот метод запускается перед каждым тестом автоматически. 
Здесь создается объект для последующего использования в тестах.  
2. test_add_new_book_add_two_books 
Тестирует добавление двух новых книг в коллекцию. 
Создается два экземпляра книг, проверяется, что обе книги появились в коллекции, 
подсчитывая общее число книг.  
3. test_set_book_genre_valid_data 
Проверяет установку жанра книги. 
Сначала добавляем книгу, потом присваиваем ей жанр («Детективы») и убеждаемся, что книга получила указанный жанр.  
4. test_get_book_genre_existing_book 
Проверяет получение жанра конкретной книги. 
Устанавливаем книжке жанр («Романы»), а затем проверяем, что вернувшийся жанр совпадает с установленным ранее.  
5. test_get_books_with_specific_genre_valid_genre 
Проверяет вывод списка книг по выбранному жанру. 
Добавляется одна книга с определенным жанром («Фантастика»), затем запрашиваются книги этого жанра и проверяется совпадение результатов.  
6. test_get_books_genre_all_books Проверяет возврат полного списка книг с указанием жанров. 
Добавляются две книги без указания жанра, ожидается пустой словарь жанров для каждой книги.  
7. test_get_books_for_children_exclude_adult_genres 
Проверяет фильтр детских книг. 
Книги разделяются на предназначенные для детей и взрослых по жанрам, затем проверяется, что детский фильтр отбрасывает неподходящие книги («Ужасы»).  
8. test_add_book_in_favorites 
Проверяет добавление книги в избранное. 
Книга сначала добавляется в библиотеку, затем помещается в избранное, после чего проверяется присутствие книги в списке избранных.  
9. test_delete_book_from_favorites Проверяет удаление книги из избранного. 
После помещения книги в избранное проверяется успешность удаления книги оттуда.  
10. test_get_list_of_favorites_books Проверяет возвращение списка избранных книг. 
Добавленная в избранное книга должна появиться в итоговом списке, возвращаемом методом.
